# QR 출석 · 위촉장

명단 엑셀만 올리면 강의실 화면에 QR이 뜨고, 참석자가 휴대폰으로 찍어 이름을 고르면 화면에 이름이 하나씩 켜집니다.
명단 없이 **오는 대로 받는 방명록**으로도, 명단 + 갑자기 온 사람을 함께 받는 **혼합형**으로도 쓸 수 있습니다.
출석부 엑셀, 새 회차 시작, 위촉장·수료증 받기까지 웹페이지 하나로 합니다. 구글 Apps Script는 쓰지 않습니다.

| 화면 | 주소 | 누가 |
|---|---|---|
| 처음 화면 | `index.html` | 담당자 |
| 행사 만들기·고치기 | `admin.html` | 담당자 (공용 비밀번호 / 관리 링크) |
| 강의실 화면 | `screen.html?e=행사번호` | 강의실 노트북·프로젝터 |
| 참석자 화면 | `join.html?e=행사번호` | 참석자 휴대폰 (QR) |
| 위촉장·수료증 | `cert.html?e=행사번호` | 참석자 휴대폰 |

- 웹페이지: GitHub Pages
- 출석 기록·명단·이미지: Supabase(무료 데이터베이스)
- 행사(명단·출석 기록·이미지)는 **마지막으로 쓴 날부터 10일 뒤 자동으로 지워집니다.** 출석·새 회차·설정 저장을 할 때마다 10일씩 늦춰집니다. 출석부 엑셀은 미리 받아 두세요.
  - 기간은 `setup.sql`의 `_keep()` 한 줄(`10 days`)만 고쳐 다시 실행하면 바뀝니다.
- 저장하는 개인정보는 연번·부서·직위·성명, 그리고 명단에 있으면 연락처입니다. 연락처는 관리 열쇠가 있어야만 읽히며(강의실 화면의 미참석자 창), 참석자 화면·공개 함수에는 나오지 않습니다. 다른 칸은 버립니다.

## 출석 방식 세 가지

행사를 만들 때 방식을 따로 고르지 않습니다. **명단을 올렸는지**와 2단계의 **"명단에 없는 사람도 출석 받기"** 스위치로 정해집니다.

| 방식 | 명단 | 명단에 없는 사람도 받기 | 휴대폰 화면 |
|---|---|---|---|
| 명단형 (예전과 같음) | 올림 | 끔 | 명단에서 내 이름 고르기 |
| 혼합형 | 올림 | 켬 | 이름 고르기 + "명단에 없어요 · 직접 쓰기" |
| 명단 없는 형 (방명록) | 안 올림 | 켬 | 부서·이름 직접 쓰기 |

- 직접 쓴 사람은 강의실 화면에 도착 순서대로 칸이 채워지고(칸이 모자라면 저절로 늘어남), 엑셀에 **구분: 추가**로 나옵니다.
- 직접 쓸 때 부서는 추천 버튼으로 고를 수 있습니다(2단계의 부서 목록, 없으면 명단에 있는 부서).
- 같은 부서·같은 이름은 한 번만 들어갑니다. 명단에 있는 사람이 직접 써도 명단의 그 사람으로 처리됩니다.

### 여러 번 내기·대리 출석 막기 (1단계 기본 정보)

- **한 휴대폰은 한 사람만** (새 행사는 기본으로 켜짐. 예전에 만든 행사는 꺼진 채 그대로)
  - 한 휴대폰으로 낸 뒤에는 다른 이름으로 또 낼 수 없습니다. 잘못 골랐으면 "내 이름이 아니에요"로 본인 것을 되돌리고 다시 고릅니다.
  - 퇴실 체크를 쓰면 **입실한 휴대폰으로만 퇴실**할 수 있습니다. 엑셀의 **상태** 칸에 `완료 / 퇴실 없음 / 퇴실만`이 나옵니다.
  - 휴대폰이 없거나 꺼진 사람은 강의실 화면의 **직접 출석 처리**(명단에 없는 사람)·**미참석자 → 출석 처리/퇴실 처리**(명단에 있는 사람)로 담당자가 대신 처리합니다. 엑셀 **비고**에 `담당자 입실 처리`로 남습니다.
  - 한계: 휴대폰 두 대, 또는 한 휴대폰의 다른 앱(크롬·삼성 인터넷 등)으로는 두 번 낼 수 있습니다. 로그인 없이 QR만으로 받는 방식에서는 완전히 막을 수 없습니다. 반대로 입실은 카메라 앱으로, 퇴실은 다른 앱으로 찍으면 "같은 휴대폰·같은 앱으로 찍어 주세요"가 뜹니다(담당자가 퇴실 처리하면 됩니다).
- **30초마다 바뀌는 QR**
  - QR을 사진 찍어 보내거나 주소를 복사해 줘도 1분 안에 못 쓰게 됩니다. 그 자리에 있는 사람만 출석할 수 있습니다.
  - QR은 **관리 링크로 연 강의실 화면**에만 나옵니다. A4 안내문·링크로는 출석할 수 없습니다.
- 이 옵션을 꺼 둔 행사도 엑셀 **비고**에 `같은 휴대폰 n명`이 표시되어, 한 휴대폰으로 여러 명을 낸 경우를 나중에 알 수 있습니다.

## 처음 한 번만: Supabase 설정 (약 10분)

1. https://supabase.com 에 가입하고 **New project**를 만듭니다.
   - 이름: 아무거나 (예: `edu-attendance`)
   - Region: **Northeast Asia (Seoul)**
   - Database password는 자동 생성된 것을 쓰고 따로 적어 둡니다(이 시스템에서는 안 씁니다).
2. 왼쪽 메뉴 **SQL Editor** → **New query** → `supabase/setup.sql` 내용을 전부 붙여 넣습니다.
3. 맨 아래 줄의 `'여기에-비밀번호'`를 **행사 만들기 공용 비밀번호**로 바꾸고 **Run**을 누릅니다.
   - "Success. No rows returned"가 나오면 됩니다.
   - 비밀번호를 바꾸고 싶으면 그 줄만 고쳐 다시 실행하면 됩니다.
4. 왼쪽 아래 **Project Settings → API Keys**(또는 **Data API**)에서 두 가지를 복사합니다.
   - **Project URL** (예: `https://abcd1234.supabase.co`)
   - **공개용 키**: `publishable` 키(`sb_publishable_…`) 또는 예전 이름 `anon` `public` 키(`eyJ…`)
   - ⚠️ `secret` / `service_role` 키는 **절대** 쓰지 마세요.
5. `config.js`에 붙여 넣습니다.

```js
window.APP_CONFIG = {
  supabaseUrl: 'https://abcd1234.supabase.co',
  supabaseKey: 'sb_publishable_...'
};
```

> 공개용 키는 웹페이지에 들어가도 되는 키입니다. 이 시스템의 표는 바깥에서 직접 읽거나 쓸 수 없게 막혀 있고, `setup.sql`의 함수(출석 제출, 화면 조회 등)만 부를 수 있습니다. 설정 고치기·엑셀·새 회차·삭제는 행사마다 만들어지는 **관리 열쇠**가 있어야 합니다.

> Supabase 무료 요금제는 오래(현재 약 1주일) 쓰지 않으면 프로젝트가 일시 중지될 수 있습니다. 그러면 Supabase 대시보드에서 **Restore(재시작)**를 누르면 됩니다. 교육 전날 강의실 화면을 한 번 열어 보면 안전합니다.

## GitHub Pages에 올리기

1. 이 폴더 전체를 GitHub 저장소(예: `edu-attendance`)에 올립니다.
2. 저장소 **Settings → Pages → Branch: main / (root)** → Save.
3. 1분쯤 뒤 `https://<계정>.github.io/edu-attendance/` 로 열립니다.

## GitLab Pages에 올릴 때

1. GitLab에서 새 프로젝트(예: `edu-attendance`)를 만들고 이 폴더 전체를 올립니다. `.gitlab-ci.yml`이 같이 올라가야 합니다.
2. 올리면 자동으로 배포 작업(CI/CD → Pipelines)이 돌고, 몇 분 뒤 **Deploy → Pages**에 주소가 나옵니다(예: `https://<계정>.gitlab.io/edu-attendance/`).
3. 참석자가 로그인 없이 열 수 있게 **Settings → General → Visibility → Pages**를 "Everyone"으로 둡니다.

## 쓰는 순서

1. 처음 화면 → **새 행사 만들기**
   1. 기본 정보: 행사 이름, 부제, 주관 부서, 첫 회차 이름
   2. 명단: 엑셀을 끌어다 놓기 → 어느 열이 부서·직위·성명인지 확인
   3. 출석 화면: 테마 12종(중랑 카드·3D 아파트·은하수·장미축제·소원 등불·새싹 숲·칠판·메모 게시판·전광판·중랑행 열차·바닷속·금빛 명패), 색, 로고·배경, 문구
   4. 위촉장·수료증: 켜기/끄기, 종류·본문·명의·날짜, 받는 사람 칸, 출석한 사람만, 마크·직인·슬로건·인쇄용 서식
   5. 공용 비밀번호를 넣고 **행사 만들기**
2. 완료 화면에서 링크를 받습니다.
   - **강의실 화면(담당자용)**: 이 링크로 열어야 아래 관리 도구가 보입니다. 열면 주소창의 열쇠 부분은 자동으로 숨겨집니다.
   - **참석자 QR**: A4 안내문으로도 내려받을 수 있습니다.
   - **관리 링크**: 잃어버리면 설정을 고칠 수 없습니다. 이 브라우저 처음 화면에도 저장됩니다.
3. 강의실 화면에서 마우스를 움직이면 관리 도구가 나옵니다.
   - **엑셀: 이번 회차** / **엑셀: 전체 출석부**(회차별 출석 시각과 출석 횟수)
   - **새 회차 시작**: 화면을 비우고 다음 회차를 받습니다. 지난 기록은 그대로 남습니다.
   - **회차 이름 바꾸기**, **전체 화면**, **설정 고치기**
   - **퇴실 받기 시작**: 같은 QR을 찍으면 퇴실로 기록됩니다. 퇴실한 사람 칸은 불이 꺼지고, 엑셀에 퇴실 시각이 나옵니다. **입실 받기로 돌아가기**로 되돌립니다.
   - **미참석자**: 이번 회차 미입실(퇴실 받는 중에는 미퇴실) 명단을 부서별로, 연락처와 함께 보여 줍니다. 복사·엑셀로 받기. 한 사람씩 **출석 처리/퇴실 처리**(담당자가 대신)도 여기서 합니다.
   - **직접 출석 처리**: 명단에 없는 사람을 담당자가 이름·부서를 써서 넣습니다.
   - 출석한 칸을 누르면 그 사람의 이번 회차 출석(퇴실 받는 중에는 퇴실)을 취소합니다.

## 이미 쓰던 저장소 업데이트

새 기능(입실·퇴실, 연락처, 명단 밖 출석, 한 휴대폰 한 사람, 바뀌는 QR, 테마 12종)이 추가된 버전으로 올릴 때는 이 순서로 합니다.

1. Supabase **SQL Editor**에서 `supabase/update.sql` 전체를 붙여 넣고 **Run** 합니다. 기존 행사·기록·비밀번호는 그대로입니다. (`setup.sql`은 맨 아래 줄이 비밀번호를 바꾸므로 업데이트에는 쓰지 않습니다.)
2. 이 폴더의 파일을 GitHub 저장소에 덮어써 올립니다(`config.js`는 그대로 둡니다).
3. 1~2분 뒤 강의실 화면을 새로고침합니다. 참석자 휴대폰은 QR을 다시 찍으면 새 화면이 뜹니다.

SQL을 먼저 실행하고 파일을 올리는 순서가 안전합니다. 순서가 바뀌어도 예전 기능은 그대로 돌아가고, 새 기능만 SQL을 실행한 뒤부터 됩니다.

## 자주 묻는 것

| 증상 | 해결 |
|---|---|
| 행정망 PC에서 강의실 화면이 안 열림 | Supabase 주소가 막혀 있을 수 있습니다. 와이파이 노트북으로 띄우세요. 참석자 휴대폰(LTE)은 상관없습니다 |
| 화면 아래 "연결이 끊겨 다시 연결하는 중" | 인터넷 연결을 확인하세요. 다시 연결되면 저절로 이어집니다. 오래 안 쓴 경우 Supabase 프로젝트가 일시 중지됐는지 확인하세요 |
| 관리 도구가 안 보임 | 담당자용 링크(관리 링크로 연 탭)로 열어야 합니다. 처음 화면의 **강의실 화면** 버튼을 쓰세요 |
| 시험으로 출석한 기록을 지우고 싶음 | 칸을 눌러 취소하거나, **새 회차 시작**으로 실제 회차를 새로 엽니다 |
| 같은 휴대폰으로 다른 사람을 출석시켜야 함 | '한 휴대폰은 한 사람만'을 켠 행사에서는 안 됩니다. 강의실 화면의 **미참석자 → 출석 처리** 또는 **직접 출석 처리**로 담당자가 대신 처리하세요. 끈 행사에서는 완료 화면 아래 "내 이름이 아니에요"로 다시 고를 수 있습니다 |
| 퇴실할 때 "같은 휴대폰·같은 앱으로 찍어 주세요" | 입실 때와 다른 앱(브라우저)으로 QR을 열었을 때 나옵니다. 같은 앱으로 다시 찍거나, 강의실 화면 **미참석자 → 미퇴실 → 퇴실 처리**로 처리하세요 |
| 휴대폰에 "QR이 바뀌었어요" | '30초마다 바뀌는 QR'을 켠 행사입니다. 강의실 화면의 QR을 다시 찍으면 됩니다 |
| 강의실 화면에 QR 대신 "담당자용 화면에서만 보여요" | 바뀌는 QR은 관리 링크로 연 강의실 화면에만 나옵니다. 처음 화면의 **강의실 화면** 버튼으로 여세요 |
| 설정을 고쳤는데 강의실 화면이 그대로 | 저장하면 열려 있는 화면에 몇 초 안에 반영됩니다. 안 되면 새로고침하세요 |
